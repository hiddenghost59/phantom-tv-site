🎯 Qu'est-ce que Phantom TV ?

Phantom TV est une application de lecture multimédia disponible sur Android, Windows et Amazon Firestick. Elle vous permet de regarder vos chaînes TV en direct, vos films et séries, et d'écouter la radio — le tout depuis une interface moderne et fluide.

💡 Bon à savoir : Phantom TV est un lecteur multimédia. Le contenu que vous regardez provient de votre propre abonnement multimédia, renseigné lors de la configuration initiale.

🚀 Premiers pas
1

Télécharger et installer l'application

Rendez-vous sur phantom-tv.fr ou directement sur Google Play pour Android, ou sur APKPure pour l'APK direct.

2

Activer votre licence

Au premier lancement, entrez la clé d'activation qui vous a été fournie lors de votre abonnement. Cette clé est personnelle et liée à votre compte.

3

Configurer votre profil

Renseignez les informations de votre fournisseur : URL du serveur, nom d'utilisateur et mot de passe. Ces informations vous sont fournies par votre prestataire.

4

Profiter du contenu

Le catalogue se charge automatiquement. Naviguez entre Live TV, Films, Séries et Radio depuis le menu principal.

🔥 Installation sur Firestick
1

Autoriser les sources inconnues

Sur votre Firestick : Paramètres → Mon Fire TV → Options pour développeurs → Activer "Applications de sources inconnues".

2

Installer Downloader

Cherchez "Downloader" dans l'Amazon Appstore et installez l'application.

3

Entrer le code Phantom TV

Ouvrez Downloader, entrez le code disponible sur phantom-tv.fr dans la section Firestick, et confirmez le téléchargement.

4

Installer et lancer

Une fois téléchargé, installez l'APK et lancez Phantom TV. La navigation D-pad est entièrement supportée.

📺 TV Gratuite

Qu'est-ce que la TV Gratuite ?

La section TV Gratuite vous donne accès à des milliers de chaînes publiques et légales du monde entier, sans avoir besoin d'un fournisseur. Ces chaînes sont issues du projet communautaire IPTV-org et sont mises à jour régulièrement.

  • Version Gratuite : accès aux chaînes françaises uniquement
  • Version Premium : accès à plus de 5 000 chaînes mondiales

⚠️ Pourquoi certaines chaînes ne fonctionnent pas ?

Ces chaînes ne sont pas gérées par Phantom TV. Elles sont diffusées par des tiers sur internet et peuvent être temporairement indisponibles, mal encodées ou géo-bloquées. C'est un comportement normal et indépendant de l'application. Si une chaîne ne fonctionne pas, essayez-en une autre ou réessayez plus tard.

Comment accéder à la TV Gratuite ?

Depuis le menu principal, appuyez sur la tuile verte "TV Gratuite". Les chaînes se chargent automatiquement. Vous pouvez filtrer par catégorie (News, Sports, Kids...) ou rechercher une chaîne par nom.

🎁 Parrainage

Comment fonctionne le parrainage ?

Chaque utilisateur de Phantom TV dispose d'un code de parrainage unique de 6 caractères, visible dans la section Parrainage de l'application. En partageant ce code à vos amis, vous gagnez des récompenses dès leur inscription.

Comment entrer un code de parrainage ?

Lors de l'activation de l'application, un champ optionnel "Code de parrainage" est disponible sous le champ de clé d'activation. Entrez le code de votre parrain avant de valider. La récompense est appliquée automatiquement.

Attention : le code de parrainage ne peut être saisi qu'une seule fois, lors de la première activation.

Quelles sont les récompenses ?

  • Parrain Gratuit + Filleul Gratuit → 1 mois Premium offert au parrain
  • Parrain Gratuit + Filleul Premium → 2 mois Premium offerts au parrain
  • Parrain Gratuit + 10 filleuls Premium → Accès Premium à vie !
  • Parrain Premium + Filleul Gratuit → +1 appareil supplémentaire
  • Parrain Premium + Filleul Premium → +2 appareils supplémentaires (max 5)
☁️ Sauvegarde du profil

Mon profil est-il sauvegardé ?

Oui ! Phantom TV sauvegarde automatiquement votre profil de connexion (URL du serveur, identifiant, mot de passe) de façon chiffrée dans le cloud. Seule votre clé d'activation permet de déchiffrer ces données — même Phantom TV ne peut pas les lire.

Comment restaurer mon profil après une réinstallation ?

Après avoir réinstallé l'application, entrez simplement votre clé d'activation. L'application récupère automatiquement votre profil depuis le cloud et vous reconnecte sans avoir à retaper vos identifiants.

🔥 Mise à jour sur Firestick

Comment mettre à jour Phantom TV sur Firestick ?

Lorsqu'une nouvelle version est disponible, un bandeau de notification apparaît en haut de l'application avec le code Downloader à utiliser. Voici la procédure :

  1. Notez le code Downloader affiché dans le bandeau
  2. Ouvrez l'application Downloader sur votre Firestick
  3. Entrez le code dans le champ prévu
  4. Téléchargez et installez la nouvelle version

Vous pouvez aussi appuyer sur "Ouvrir dans Silk Browser" dans le bandeau — le navigateur s'ouvrira avec le lien de téléchargement direct.

Pourquoi dois-je désinstaller avant de mettre à jour ?

Sur Firestick, l'installation d'une nouvelle version via Downloader nécessite parfois de désinstaller l'ancienne version d'abord. Rassurez-vous : votre profil est sauvegardé dans le cloud — il sera restauré automatiquement après réinstallation grâce à votre clé d'activation.

❓ Questions fréquentes

🔑 J'ai perdu ma clé d'activation

Contactez-nous via la section Contact de l'application ou par email à contact@phantom-tv.fr, nous vous la renverrons rapidement.

📱 Puis-je utiliser Phantom TV sur plusieurs appareils ?

Avec le plan Premium, vous pouvez activer Phantom TV sur jusqu'à 3 appareils simultanément avec la même clé d'activation.

🔄 Comment mettre à jour l'application ?

Une bannière de mise à jour s'affiche automatiquement dans l'application lorsqu'une nouvelle version est disponible. Suivez le lien pour télécharger la dernière version.

⚡ La lecture est lente ou coupe

Vérifiez votre connexion internet (une connexion de 10 Mbps minimum est recommandée pour la HD, 25 Mbps pour la 4K). Si le problème persiste, il peut venir du serveur de votre fournisseur.

🎬 Un film ou une série ne se lance pas

Certains contenus peuvent être temporairement indisponibles chez votre fournisseur. Phantom TV essaie automatiquement plusieurs formats de lecture — si aucun ne fonctionne, le contenu est probablement indisponible à ce moment-là.
